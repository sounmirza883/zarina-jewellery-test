# Image guide

Replace these placeholders with real photos. Missing images show a neutral beige placeholder.

| Folder | File pattern | Size |
| --- | --- | --- |
| products | `<product-slug>-1.jpg`, `-2.jpg`, ... (names come from `data/products.ts`) | 1000 x 1250 px |
| hero | `corner-tl.jpg`, `corner-tr.jpg`, `corner-bl.jpg`, `corner-br.jpg` | 1600 x 900 px |
| brand | `category-earrings.jpg`, `category-necklaces.jpg`, `category-rings.jpg`, `category-bracelets.jpg` | 800 x 800 px |
| brand | `story.jpg`, `ceo.jpg` | 1000 x 1250 px |
| brand | `og-image.jpg` (social sharing preview) | 1200 x 630 px |

Tips: export as JPG at about 80 percent quality. Keep each file under 250 KB. next/image creates smaller WebP and AVIF versions automatically.
